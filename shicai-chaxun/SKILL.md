# 食物营养查询 Skill

查询食物营养成分与嘌呤含量的标准化流程，适用于高尿酸/痛风人群的饮食管理场景。

## 何时使用

当用户询问以下内容时使用本 Skill：
- 某种食物的嘌呤含量、嘌呤分级（低/中/高）
- 某种食物的热量、蛋白质、脂肪、碳水、膳食纤维
- 某种食物的维生素、矿物质含量
- 痛风/高尿酸人群能不能吃某种食物
- 对比几种食物的营养差异

## 核心规则

### 1. 嘌呤分级标准（铁律）

以《成人高尿酸血症与痛风食养指南（2024版）》为准：

| 分级 | 嘌呤含量（mg/100g） |
|------|---------------------|
| 低嘌呤 | < 50 |
| 中嘌呤 | 50 – 150 |
| 高嘌呤 | > 150 |

此标准不随意变动。如用户提出不同标准，先说明权威出处，再按用户要求执行。

### 2. 数据源优先级

按以下顺序查找数据，优先用排在前面的：

1. **《中国食物成分表标准版第6版》纸质书**
- 嘌呤以第二册表六（490种实测）为准，是嘌呤对照的唯一基准
- 第一册：植物性食物（谷薯豆菜菌藻果坚果油脂）
- 第二册：动物性食物
2. **中国食物成分在线查询平台**（https://www.foodcomposition.cn/）
- 查宏量营养素：能量、蛋白、脂肪、碳水、膳食纤维、矿物质
- 无嘌呤数据
3. **《成人高尿酸血症与痛风食养指南（2024）》**：嘌呤分级定性参考
4. **WS/T 560—2017**：旧版行业标准对照
5. **USDA FoodData Central**：进口食材对照
6. **USDA & ODS-NIH Purine Database**：嘌呤碱基细分（区分总嘌呤/游离嘌呤）
7. **日本食品标准成分表**：东亚海鲜藻类对照
8. **Kaneko 文献**：医院嘌呤表溯源

**总口径**：有中国权威来源时优先用中国，不以日本表覆盖中国数据。

### 3. 数据诚实原则

- 核实不到的数据标"—"（或 null），**绝不编造**
- 估算值必须明确标注"估算"或"参照同类"
- 同一食材的不同状态（干/鲜/泡发/煮熟/生/熟）必须分开查，不能混用

### 4. 痛风人群特别提醒

查询结果中如涉及以下情况，主动提醒：
- 高果糖食物：果汁、含糖饮料（果糖升尿酸不亚于酒精）
- 酒精：啤酒、白酒等（即使嘌呤低也要提醒）
- 浓肉汤、火锅汤：嘌呤易溶于水，汤比肉更危险
- 干货 vs 鲜货：干香菇、干紫菜等干货嘌呤远高于鲜货

## 查询流程

### 步骤一：确定食材

1. 确认食材的准确名称（含状态：干/鲜/泡发/煮熟等）
2. 如名称有歧义（如"橘子"可能是柑橘/蜜橘/砂糖橘），先跟用户确认具体是哪种

### 步骤二：查找嘌呤

1. 先查《中国食物成分表》第二册表六
2. 表六没有 → 查 2024 指南 / WS/T 560 附表
3. 还没有 → 查 USDA & NIH / 日本表 / Kaneko 文献
4. 都没有 → 标"—"，说明"暂无权威数据"

### 步骤三：查找营养素

1. 能量、蛋白、脂肪、碳水 → 中国食物成分在线查询平台
2. 维生素、矿物质 → 同上，或 USDA FoodData Central
3. 膳食纤维注意口径：总膳食纤维 = 可溶性 + 不可溶性

### 步骤四：输出

按以下格式返回（单位必须标注）：

```
【食物名】
嘌呤：XX mg/100g（低/中/高嘌呤）
热量：XX kcal/100g
蛋白质：XX g/100g
脂肪：XX g/100g
碳水：XX g/100g
膳食纤维：XX g/100g
[其他相关营养素...]
数据来源：[具体出处]
备注：[痛风相关提醒，如有]
```

## 示例

### 示例1：查嘌呤

**用户问**："香菇嘌呤高吗？"

**处理**：
1. 确认：鲜香菇还是干香菇？（两者嘌呤差很多）
2. 查表六：鲜香菇 XX mg/100g，干香菇 XX mg/100g
3. 按标准分级
4. 输出时提醒：干香菇嘌呤远高于鲜香菇，痛风急性期避免

### 示例2：能不能吃

**用户问**："痛风能吃豆腐吗？"

**处理**：
1. 查嘌呤：豆腐约60-70 mg/100g，中嘌呤
2. 判断：急性期不建议，缓解期可适量吃
3. 输出：嘌呤值 + 分级 + 分期建议
4. 提醒：不要因噎废食，豆制品是优质蛋白来源；同时提醒避免浓豆浆大量饮用

### 示例3：对比

**用户问**："草鱼和鲫鱼哪个嘌呤高？"

**处理**：
1. 分别查表六：草鱼 XX，鲫鱼 XX
2. 对比数值和分级
3. 输出对比表格
4. 如都在中嘌呤区间，说明"两者接近，控制总量更重要"

## 常见坑（必看）

以下情况最容易查错或误导用户，务必注意：

1. **干货 vs 鲜货**：干香菇（405）vs 鲜香菇（~50）、干紫菜（415）vs 鲜紫菜（~30），差一个数量级。用户只说"香菇"时必须追问干/鲜。

2. **果汁 vs 水果**：水果本身嘌呤低，但榨汁后丢失纤维、浓缩果糖，升尿酸效果不亚于酒精。用户问"能不能喝橙汁"时，不能只看嘌呤值。

3. **汤 vs 肉**：嘌呤易溶于水，浓肉汤、火锅汤的嘌呤比肉本身更高。用户问"喝汤行不行"时要明确警告。

4. **啤酒的特殊性**：啤酒嘌呤值本身不高（~8），但酒精会抑制尿酸排泄。不能因为嘌呤低就说"能喝"。

5. **豆制品的误区**：很多人以为豆制品高嘌呤不能吃。实际上豆腐（~60-70）是中嘌呤，痛风缓解期适量可吃；豆浆嘌呤更低。不要一刀切说"不能吃豆制品"。

6. **同名不同物**：比如"橘子"可能是柑橘/蜜橘/砂糖橘，"鱼"有几十种。名称模糊时先确认具体品种。

## 注意事项

- 不要把"最后修改时间"当成数据可信度依据
- 跨境食材（如进口三文鱼）优先用 USDA 数据，但分级仍按中国标准
- 本 Skill 附带的表六490条为书上原文，可直接引用；用户自建的632条数据库仍在核对中，暂未收录，等核对完成后再更新
